# Project Identity and Trademark Guidelines

The Apache License 2.0 governs the Fate UI source code. Section 6 of that license does not grant rights to project names, trade names, logos, service marks, or product marks except for reasonable use in describing the software's origin and reproducing attribution notices.

## Permitted uses

You may:

- state truthfully that your work is based on or compatible with Fate UI;
- link to the original project;
- reproduce required attribution from [NOTICE](NOTICE);
- use the name in commentary, reviews, tutorials, and other nominative references.

## Uses requiring permission

Without written permission, do not:

- present a modified build as an official or unmodified Fate UI release;
- imply endorsement, sponsorship, or affiliation with the maintainers;
- use the Fate UI name or application mark as the primary branding of a materially modified distribution;
- remove required attribution and claim the original project as your own work.

Forks and modified distributions should use a distinct primary name and visual identity while retaining the attribution required by Apache-2.0 and NOTICE. This protects users from confusing unofficial builds with releases published by the original project.

These guidelines describe project identity; they do not add restrictions to the Apache-licensed source code. They are not a claim that any mark is registered in every jurisdiction.
